Introduction

HTML digunakan untuk struktur halaman web, CSS digunakan untuk styling.

<h1>Hello World</h1>

HTML Tags

Tag umum: heading, paragraph, link, image.

<a href="#">Klik Saya</a>

HTML Lists

Membuat daftar berurutan dan tidak berurutan.

<ul><li>Item</li></ul>

HTML Tables

Tabel digunakan menampilkan data.

<table><tr><td>A</td></tr></table>

HTML Forms

Form untuk input data user.

<input placeholder='Nama'>

Semantic HTML

Gunakan header, main, footer.

<header>Header</header>

HTML Media

Tambahkan audio dan video.

<video controls></video>

CSS Selectors

Gunakan selector untuk memilih elemen.

<style>h1{color:tomato;}</style>
<h1>Judul</h1>

CSS Colors

Atur warna elemen.

<style>h1{color:red}</style>

Box Model

Margin, border, padding.

padding:20px;

CSS Position

Relative dan absolute.

position:relative;

Flexbox

Flexbox memudahkan layout horizontal dan vertikal.

<style>.wrap{display:flex;gap:10px}.box{background:#0ea5e9;color:#fff;padding:20px}</style>

CSS Grid

Layout berbasis kolom.

Responsive Design

Gunakan media query.
