Modul 01 / Pengenalan

Apa Itu Laravel?

Laravel adalah framework PHP open-source yang digunakan untuk membangun aplikasi web dengan lebih cepat, terstruktur, dan efisien. Framework ini menyediakan berbagai fitur dasar sehingga developer tidak perlu menulis modul teknis dari awal.

Laravel Membantu Developer

  • Membuat website dengan tempo lebih cepat
  • Mengelola basis data secara lebih mudah
  • Menjaga struktur kode agar tetap rapi
  • Mempermudah proses kolaborasi dalam tim

Mengapa Laravel Sangat Populer?

  • Sangat mudah dipelajari oleh pemula
  • Dokumentasi panduan resmi yang sangat lengkap
  • Memiliki komunitas global yang sangat masif
  • Cocok untuk skala proyek kecil hingga korporat

Modul 02 / Historis

Sejarah Singkat Laravel

Bagaimana sebuah proyek hobi berkembang menjadi salah satu pilar utama ekosistem pengembangan web modern di seluruh dunia?

Taylor Otwell (2011)

Laravel pertama kali dikembangkan oleh Taylor Otwell dan dirilis secara publik pada tahun 2011.

Kerangka kerja ini awalnya diciptakan sebagai solusi alternatif yang lebih bersih dan fleksibel untuk menggantikan beberapa framework PHP generasi sebelumnya yang dianggap memiliki kurva belajar yang terlalu rumit serta sintaks yang kaku.

Taylor ingin menghadirkan framework dengan kesederhanaan menulis kode (*expressive syntax*) yang dilengkapi dengan buku panduan dokumentasi yang rapi dan menyenangkan bagi semua level pemrogram.

FAKTA UTAMA

Taylor Otwell

Pencipta & pimpinan utama desain arsitektur framework Laravel dari versi 1 hingga versi modern hari ini.

Tahun Rilis: 2011

Modul 03 / Filosofi

Tujuan Dibuatnya Laravel

Laravel bukan hanya tentang mempermudah penulisan baris kode, melainkan tentang menyederhanakan alur kerja agar pengembang dapat fokus pada kreativitas produk.

Akselerasi Pengoperasian

Mengurangi penulisan baris kode yang berulang agar proses perampungan website berjalan jauh lebih cepat.

Keamanan Tingkat Tinggi

Perlindungan bawaan dari SQL Injection, Cross-Site Scripting (XSS), dan pemalsuan request CSRF.

Kemudahan Pemeliharaan

Struktur kode yang seragam memudahkan tim baru untuk melanjutkan pemeliharaan di masa mendatang.

“

Write Less, Do More

Tulis baris kode sekedarnya untuk memicu hasil fungsional yang sebesar-besarnya di balik layar.

Modul 04 / Dasar Teori

Apa Itu Framework?

Memahami perbedaan mendasar saat menulis kode aplikasi web menggunakan cara mentah (*raw*) vs terstruktur menggunakan kerangka kerja (*framework*).

Coding Tanpa Framework

Programmer wajib merancang sistem routing, membuat modul koneksi database manual, menyusun aturan keamanan, dan menata berkas file dari nol secara berulang-ulang untuk setiap proyek baru.

Coding Dengan Framework

Sistem inti telah tersedia rapi. Programmer bisa langsung memfokuskan energi mereka untuk mengembangkan logika bisnis utama dan fitur-fitur yang diinginkan pengguna.

Analogi Kerangka Bangunan

Framework diibaratkan sebagai **kerangka dasar struktur rumah** yang sudah kokoh terpasang. Anda tidak perlu membuat pondasi semen dan kayu penyangga tiang dari awal; Anda tinggal menentukan jenis ubin, warna cat, dan mebel untuk mempercantik rumah tersebut.

Modul 05 / Arsitektur

Arsitektur MVC

Laravel mengandalkan arsitektur **Model-View-Controller (MVC)** untuk memisahkan logika data, antarmuka pengguna, dan penengah instruksi aplikasi.

M Model

Mengatur pengelolaan komunikasi data langsung dengan basis data (*database*). Seperti menyimpan, mengubah, mengambil, dan menghapus catatan data.

Analogi: Petugas Gudang
V View

Bertanggung jawab terhadap seluruh struktur tampilan antarmuka visual yang dilihat dan diinteraksikan langsung oleh pengguna (*user*).

Analogi: Layar/Etalase
C Controller

Penghubung lalu lintas utama. Menerima masukan permintaan dari pengguna, memproses logika, mengoordinasikannya ke Model, lalu mengirim hasilnya ke View.

Analogi: Pelayan Restoran

Simulasi Langkah Alur Kerja MVC

01. Request
Pengguna mengakses halaman web. Masuk sebagai instruksi ke Controller.
02. Data Fetch
Controller meminta catatan data yang relevan kepada Model.
03. DB Query
Model mengambil data dari database lalu mengembalikan hasilnya ke Controller.
04. View Render
Controller menyuntikkan data tersebut ke View untuk dipajang ke layar pengguna.

Modul 06 / Operasi Data

Konsep CRUD

CRUD adalah empat pilar operasi dasar pengolahan data yang akan selalu Anda temui dalam pembuatan program berskala dinamis.

C

Create

Menambahkan catatan data baru ke dalam database.

Contoh: Register Akun
R

Read

Mengambil atau menampilkan baris data dari database ke layar.

Contoh: Melihat Katalog
U

Update

Mengubah atau memperbarui nilai data yang sudah tersimpan sebelumnya.

Contoh: Edit Profil
D

Delete

Menghapus baris atau catatan data tertentu secara permanen dari database.

Contoh: Hapus Postingan

Ilustrasi Kasus Aplikasi Perpustakaan

CREATE Input Buku Baru
READ Tampil Katalog Buku
UPDATE Edit Nama Pengarang
DELETE Hapus Buku Hilang

Modul 07 / Praktikum

Instalasi & Persiapan Proyek

Langkah-langkah taktis dan spesifikasi perangkat lunak yang perlu dipersiapkan untuk memulai proyek Laravel 12 pertama Anda.

Composer

02. SERVER

04. FRONTEND

Node.js

Digunakan untuk meluncurkan aset visual lewat Vite.

Rangkuman Sesi & Penutup

Poin Penting yang Kita Pelajari

  • Filosofi Modern: "Write Less, Do More" memangkas penulisan kode berulang demi fungsionalitas maksimal.
  • Arsitektur MVC: Pemisahan fungsionalitas mutlak antara data (Model), tampilan (View), dan penengah (Controller).
  • Fondasi CRUD: Create, Read, Update, dan Delete adalah pilar rekayasa perangkat lunak berbasis database.

Langkah Kita Selanjutnya
